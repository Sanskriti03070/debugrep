# Contributing to DebugRep

We welcome new multi-file codebase problems (Bug Hunts, Feature Additions, and Performance Refactors) in **Java** and **Python**.

## How to Add a Problem
1. Fork the repo and create a branch: `git checkout -b feat/problem-your-slug`
2. Add a new problem module in `src/data/problems/` following `src/types/problem.ts`.
3. Include a realistic ticket description, 3–6 starter files with an intentional bug/task, and a visible test suite that fails on starter code and passes once fixed.
4. Register the problem in `src/data/problems/index.ts` and open a Pull Request.
